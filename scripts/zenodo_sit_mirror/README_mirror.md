# SITVIT2 spoligotype patterns from SpolLineages (mirror)

This record is an unmodified copy of `Spoligo_list.csv` from the [SpolLineages](https://github.com/dcouvin/SpolLineages)
repository (commit `@COMMIT@`), mirrored for [spoligotyper](https://github.com/duceppemo/spoligotyper), which
downloads it with `spoligotyper-download-sit` when GitHub cannot be reached.

* **Content**: 9,658 spoligotype patterns of the SITVIT2 database (Institut Pasteur de Guadeloupe), with their octal
  and binary codes, SITVIT2 family, shared international type (SIT; 3,850 patterns) and country distribution.
* **SHA-256** of `Spoligo_list.csv`: `@SHA256@`
* **License**: GNU General Public License v3.0 (GPL-3.0), as in the SpolLineages repository (see `LICENSE`).
* **Authors of the data**: the SITVIT2 and SpolLineages team. This mirror adds nothing to it.
